# Instacart Exploratory Data Analysis

## Project Overview

This project performs exploratory data analysis on Instacart order and product data using Python and pandas.

## Objectives

- Inspect and understand multiple related datasets
- Examine data types and dataset structure
- Investigate missing values
- Explore relationships between orders, products, aisles, and departments
- Identify data-quality issues
- Prepare the data for further analysis

## Technologies & Libraries

- Python
- Pandas
- Matplotlib

## Data Analysis

The project works with multiple datasets containing information about:

- Orders
- Products
- Departments
- Aisles
- Order-product relationships

The analysis includes dataset inspection, DataFrame exploration, missing-data investigation, and examination of relationships between product and department information.
